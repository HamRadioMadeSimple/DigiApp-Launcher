DigiApp Launcher for Windows
================================
Opens your digital-mode radio programs in order, waiting between each one so each
program is ready before the next starts. One click on a gold taskbar icon.
(The full illustrated guide is DigiApp-Launcher-Guide.pdf.)

INSTALL
1. Double-click DigiAppLauncher-<version>-Setup.exe.
   If Windows says "Windows protected your PC": click "More info" > "Run anyway".
   (The program isn't code-signed; that's normal for small ham-radio tools.)
2. Click Yes when Windows asks for permission, then click through the setup.
   It installs to C:\Program Files\DigiApp Launcher.
3. Leave "Open DigiApp Launcher" ticked and click Finish.
   No-install option: unzip DigiApp-Launcher-<version>-Windows-Portable.zip to a folder you keep,
   double-click DigiAppLauncher.exe, and click the gold "Desktop Icon" button.

SET UP
- Add your programs: "+ Add App" > "Pick from installed apps..." or "Browse for a program...",
  or drag desktop icons onto the list.
- Move Up / Move Down for the order. Set each app's wait time (seconds to wait before the
  NEXT app opens). Tick "Minimize" for apps that should start on the taskbar.
- Pin it: right-click the DigiApp Launcher desktop icon > Show more options > Pin to taskbar.
- To change your apps later without launching any, double-click the
  "DigiApp Launcher - Edit" icon on your desktop (also in the Start menu).

EVERY DAY
- Click the taskbar icon: opens your default profile (marked with a star).
- Right-click the taskbar icon: pick another profile, "Close Open Apps" (closes them in
  reverse order and waits for any "Save changes?" questions), or edit your apps.

PROFILES
New Profile, Clone (copy and modify), Rename, Delete Profile, and Set as Default.
Everything saves automatically.

YOUR SETTINGS
Kept in %APPDATA%\DigiApp Launcher\settings.json - never with the program, so updating or
reinstalling keeps your setup.

UPDATING
Run the new Setup.exe; it keeps your profiles. If the taskbar right-click ever stops showing
your profiles: unpin it, click "Desktop Icon" in the program, and pin the new desktop icon.

UNINSTALL
Settings > Apps > Installed apps > DigiApp Launcher > Uninstall.
(Optional: delete %APPDATA%\DigiApp Launcher to remove your profiles too.)

HELP
Newest version: https://github.com/HamRadioMadeSimple/DigiApp-Launcher/releases/latest
Problems or questions: https://github.com/HamRadioMadeSimple/DigiApp-Launcher/issues
